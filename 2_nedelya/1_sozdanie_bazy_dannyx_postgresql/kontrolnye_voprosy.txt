Вопросы:
1. Синтаксис команд CREATE, ALTER, DROP.
2. Для чего нужны эти команды?
3. Какие типы могут иметь поля таблиц?

Ответы:
1.
CREATE TABLE <имя_таблицы> (
    <имя_столбца> <тип данных> <ограничение>,
    <имя_столбца> <тип данных> <ограничение>
);
ALTER TABLE <имя_таблицы> ADD COLUMN <имя_столбца>;
DROP TABLE <имя_таблицы>;

2.
CREATE TABLE - создание таблицы в базе данных;
ALTER TABLE - изменение сушествующей таблицы в базе данных;
DROP TABLE - удаление сушествующей таблицы в базе данных.

3. INTEGER, INT, VARCHAR, TEXT, DATE, BOOLEAN, NUMERIC.
