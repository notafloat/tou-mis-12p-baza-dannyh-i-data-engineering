9. Контрольные вопросы
    1.	Что такое PostgreSQL? 
    2.	Для чего используется pgAdmin? 
    3.	Что представляет собой база данных? 
    4.	Для чего предназначена команда CREATE DATABASE? 
    5.	Чем отличаются типы VARCHAR, INTEGER и DATE? 
    6.	Что такое первичный ключ? 
    7.	Для чего используется внешний ключ? 
    8.	Каково назначение ограничений NOT NULL, UNIQUE и CHECK? 
    9.	В чём различие между командами INSERT, UPDATE и DELETE? 
    10.	Для чего используется команда SELECT? 
    11.	Что означает автоматическое поле типа SERIAL? 
    12.	Как связаны таблицы students и groups?

Ответы:
    1. Система управления базами данных с открытым кодом разработанная под руководством Майкла Стоунбрейкер.
    2. Используется как программа с графическим интерфейсом для работы и администрирования PostgreSQL.
    3. База данных это организованное и структуризированное хранилище данных которые могут быть связаны между собой. Данные могут быть представлены в виде реляционных, не реляционных, графовых структурах данных.
    4. Для создания пустой базы данных в СУБД.
    5. VARCHAR тип данных хранящая строки с лимитом символов, INTEGER тип данных хранящая целочисленные данные, DATE тип данных хранящая дату.
    6. Ключ для идентификаций записей в таблице.
    7. Для связывания данных в таблице.
    8. NOT NULL ограничивает аттрибут в таблице не давая записям этого аттрибута быть пустым, UNIQUE ограничивает аттрибут в таблице не давая записям этого аттрибута иметь дубликаты, CHECK ограничивает аттрибут создавая проверку данных.
    9. INSERT ввод данных, UPDATE изменение, DELETE удаление.
    10. SELECT используется для выборки данных из таблиц.
    11. SERIAL используется для создания атрибутов с автоинкрементируещемся целочисленных полей.
    12. Посредством внешнего ключа связанных через первичный ключ.
